# 프로젝트 표시와 네트워크 아이콘

요약: 사이트 이름은 ‘실습으로 배우는 네트워크’다. 홈과 파비콘에는 직접 작성한 네트워크 연결 SVG를 사용하며 MIT로 제공한다. 아올다 로고·아이콘은 포함하지 않는다.

## 아이콘과 이용 조건

`content/assets/network-icon.svg`는 세 단말과 가운데 연결 지점을 기본 도형으로 표현한 프로젝트 자체 아이콘이다. 외부 로고·아이콘 파일이나 아이콘 라이브러리를 사용하지 않았다. 사이트의 파란색 계열을 사용하며 별도 글꼴·외부 요청이 필요하지 않다. [MIT 전문](../LICENSES/MIT.txt)과 [적용 범위](../LICENSE.md)를 따른다.

## 표시와 접근성

홈의 큰 아이콘은 장식이므로 빈 alt와 aria-hidden으로 보조 기술에서 제외하고 좁은 화면에서는 숨긴다. 파비콘은 같은 SVG를 사용한다. 헤더와 학습 홈 링크는 텍스트 이름을 유지한다.

아주대학교 클라우드 운영 소학회 아올다의 4기 네트워크 스터디에서 시작한 배경은 텍스트로 설명한다. 아올다 이름에 관한 이용 허락이나 공식 후원을 뜻하지 않는다. 현재 공개 소스와 사이트에는 아올다 로고·아이콘 파일을 포함하지 않는다.
